# Company Questions

Keep solutions to interview and online assessment questions asked by companies here.
Organize solutions by company, then by question source when useful. For example:

```text
companies/
  amazon/
    interviews/
    onlineassessments/
  google/
    interviews/
    onlineassessments/
```

Use matching lowercase Java package names (for example, `companies.amazon.interviews`).
Include the company and question details in each solution so the source is clear.
